## Générer l'APK
1. Installer Flutter et Android Studio.
2. Ouvrir ce dossier dans Android Studio.
3. Dans le terminal : `flutter pub get`
4. Tester : `flutter run`
5. Générer l'APK : `flutter build apk --release`

APK : `build/app/outputs/flutter-apk/app-release.apk`
